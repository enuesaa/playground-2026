# void

- 今や cloudflare の void
- 癖は少なそう
- というか vite + alpha 的な存在っぽい
  - svelte に対応している
- dbを選ぶときにd1が選択肢に出てくるのやっぱcloudflareの影響受けているなとは思った。

```bash

npx void init

### cloduflare へデプロイできる
npx void deploy

### delete はコンソールからっぽい。コマンド分からんかった
```
