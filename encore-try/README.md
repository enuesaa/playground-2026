# Encore

- ウェブアプリ開発のプラットフォームライク
- こちらで実装必要なのは、アプリのコードだけ。
  - wasm のアプリを開発しているときみたい
  - もしくは Lambda のハンドラーを実装している気分
- Go と TypeScript の binding があるっぽい
- プラットフォームエンジニアリングを突き詰めたらこんな感じになるのかなあ。
- 開発元が Encore というプラットフォームを運営しており、そこへアプリケーションをデプロイできる
- ライセンス注意

## Commands
```bash
# Install
brew install encoredev/tap/encore
encore version

# Create app
encore app create

# Run app
encore run
```
