# Cloudflare Bulk Redirect

- リダイレクトのリストを登録できる
- これは便利
- 適用対象は Cloudflare で管理しているサイトっぽい
  - 当たり前だが。
  - 管理対象外のドメインもなんか入力できるっぽいけど実際のところリダイレクトされないと思う。だって無理なので。
- 基本的には cloudflare の rule の1機能っぽいが、ドメインの方のページとは独立していて、自分が管理しているサイト全体に適用されるっぽい
- ステータスコードも指定可能。302とか
