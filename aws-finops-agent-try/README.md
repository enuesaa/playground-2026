# AWS FinOps Agent

- プレビュー
- DevOps Agent の料金版って印象
- いわゆるチャットUIで料金の分析 & アーティファクト(HTML) を作成できるっぽい
- Billing and Cost Management から FinOps Agent へとべる
- オーガニゼーション全体での有効化（委任アカウントの設定）が推奨されているっぽい
  - けど実情としてスモールスタートには向いてないからあえて単一アカウントでだけ導入してみている
- 調査用の IAM Role の権限を適切に絞れば、上手いこと使えそう
- どうでもいいけど作成されたHTMLファイルがダークモードにも対応していて感動した。
  - AWSコンソールのUIにうまいことハマってプレビューされていて素晴らしい
